# Earshot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Earshot — a Twitter/X Spaces-style live audio room product that runs as an embedded app inside MeWe.

**Architecture:** A single Next.js App Router application. Next.js route handlers are the entire backend. Durable state (users, rooms, roles, bans) lives in Postgres; all ephemeral state (presence, hand-raises, chat, reactions, speaking, mute) lives in LiveKit and is never persisted. Authorization is a pure-function capability matrix over a ranked role, and the *same* role value derives the LiveKit token grant so database permissions and media permissions cannot drift.

**Tech Stack:** TypeScript · Next.js (App Router) · LiveKit Cloud + `@livekit/components-react` · Neon Postgres + Drizzle · `iron-session` · Tailwind · shadcn/ui (6 components) · Vercel

**Spec:** `docs/superpowers/specs/2026-08-11-earshot-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

**Scale & scope**
- Prototype at ~10 participants per room. Not production traffic.
- Speaker cap: **10** (host counts toward it).
- Co-host cap: **2**.
- Topics per room: max **3**.
- All services must be free tier: Vercel Hobby, LiveKit Cloud free, Neon free.

**Security invariants — never relax these**
- **No role, including host, may unmute another user.** No unmute endpoint may exist. The LiveKit server API *is* capable of remote unmute; this application must never call it.
- Every action targeting another user requires `RANK[actor] > RANK[target]` in addition to the capability check.
- Bans are checked **at LiveKit token mint**, never only in the UI.
- All moderation authorization is server-side. UI enforcement alone is never sufficient.
- `X-App-Id` and `X-Api-Key` are server-only. They must never appear in client bundles.
- The MeWe `apiToken` lives only in the encrypted httpOnly session cookie, never in client JavaScript.
- All `postMessage` handlers verify `event.origin` against `MEWE_ORIGIN`. Unverified origins are ignored silently.
- LiveKit webhooks are signature-verified; unsigned requests are rejected.

**Platform**
- Runs in a cross-origin iframe inside MeWe.
- **`vh` / `vw` are forbidden.** They resolve against MeWe's viewport, not our panel. Use `--app-h` / `--app-w` written from `HOST_DISPLAY_RESPONSE`, and `cqi` / `cqb` for fluid sizing.
- **Container queries, not media queries.** Panel width has no relationship to device width.
- `HOST_APP_PAUSED` must **not** stop audio — it is a dialog, not a suspend.
- `HOST_APP_MINIMIZED` must **not** stop audio — this is the background-listening feature.
- `HOST_APP_CLOSED` **must** disconnect and release the microphone.

**Design tokens — exact values**
```css
--ink:   #0D1719;  --panel: #15252A;  --rule:  #24424B;
--bone:  #ECE6D9;  --dim:   #7E9298;  --onair: #E8442E;
```
- `--onair` is used **only** for live tally dots and the speaking ring. Never a button fill, never a hover state, never decoration.
- **Errors and warnings never use red.** They use `--bone` on `--panel`.

**Typography — exact**
- Display + body: **Archivo** (variable, axes `wdth` 62–125, `wght` 100–900). Display = `wdth 80` / `wght 600` / caps / `+0.02em`. Body = `wdth 100` / `wght 400–500`.
- Data: **Martian Mono** (variable, axes `wdth` 75–112.5, `wght` 100–800), `wght 500` / caps / `+0.08em`.
- Loaded via `next/font/google` with `axes: ['wdth']`.
- **Forbidden faces:** Inter, Geist, Space Grotesk, DM Sans.

**Accessibility floors**
- Touch targets ≥ **44px** at every size tier including the narrowest.
- Never color alone — `--onair` is always paired with a shape, glyph, or motion.
- `prefers-reduced-motion` removes the ripple and pulse; the ring becomes a static outline.
- ARIA live region announces role changes ("You are now a speaker").
- Full keyboard access to mic, ask-to-speak, and every moderation control.

**Copy rules**
- Name things by what people control: **Ask to speak**, not "Request speaker permission". **Let Sara speak**, not "Promote participant". **Start a room**, not "Submit".
- An action keeps its name through the flow: **Start a room** → toast **Room started**.
- Errors state what happened and what is still possible. They never apologize and are never vague.

**Environment variables**
```
DATABASE_URL              Neon Postgres connection string
SESSION_SECRET            iron-session password, ≥32 chars
MEWE_APP_ID               server-only
MEWE_API_KEY              server-only
MEWE_ORIGIN               e.g. https://mewe.com — postMessage origin allowlist
LIVEKIT_API_KEY           server-only
LIVEKIT_API_SECRET        server-only
NEXT_PUBLIC_LIVEKIT_URL   wss://<project>.livekit.cloud
```

```ts
export type Role = 'host' | 'cohost' | 'speaker' | 'invited' | 'listener';

export const RANK: Record<Role, number> = {
  host: 3, cohost: 2, speaker: 1, invited: 0, listener: 0,
};

export const SPEAKER_CAP = 10;
export const COHOST_CAP = 2;

export const CAN = {
  endRoom:        ['host'],
  editSettings:   ['host'],
  promote:        ['host', 'cohost'],
  demote:         ['host', 'cohost'],
  mute:           ['host', 'cohost'],
  removeOrBan:    ['host', 'cohost'],
  inviteSpeaker:  ['host', 'cohost'],
  publishAudio:   ['host', 'cohost', 'speaker'],
  chatAndReact:   ['host', 'cohost', 'speaker', 'invited', 'listener'],
  requestToSpeak: ['speaker', 'invited', 'listener'],
} as const satisfies Record<string, readonly Role[]>;

export type Action = keyof typeof CAN;

export function can(role: Role, action: Action): boolean {
  return (CAN[action] as readonly Role[]).includes(role);
}

/** Strict: equal rank does NOT outrank. This is what stops cohost-vs-cohost actions. */
export function outranks(actor: Role, target: Role): boolean {
  return RANK[actor] > RANK[target];
}

/** The only correct way to authorize an action against another user. */
export function canModerate(actor: Role, target: Role, action: Action): boolean {
  return can(actor, action) && outranks(actor, target);
}

export function canPublish(role: Role): boolean {
  return RANK[role] >= RANK.speaker;
}
```

```ts
import { pgTable, text, uuid, timestamp, integer, pgEnum, unique } from 'drizzle-orm/pg-core';

export const roomStatus = pgEnum('room_status', ['scheduled', 'live', 'ended']);
export const speakerPolicy = pgEnum('speaker_policy', ['everyone', 'invited']);
export const memberRole = pgEnum('member_role', ['host', 'cohost', 'speaker', 'invited']);

export const users = pgTable('users', {
  id: text('id').primaryKey(),                       // MeWe user id
  displayName: text('display_name').notNull(),
  avatarUrl: text('avatar_url'),
  lastSeenAt: timestamp('last_seen_at', { withTimezone: true }).defaultNow(),
});

export const rooms = pgTable('rooms', {
  id: uuid('id').primaryKey().defaultRandom(),
  title: text('title').notNull(),
  topics: text('topics').array(),
  status: roomStatus('status').notNull().default('scheduled'),
  speakerPolicy: speakerPolicy('speaker_policy').notNull().default('everyone'),
  scheduledFor: timestamp('scheduled_for', { withTimezone: true }),
  startedAt: timestamp('started_at', { withTimezone: true }),
  endedAt: timestamp('ended_at', { withTimezone: true }),
  peakListeners: integer('peak_listeners').notNull().default(0),
  livekitRoom: text('livekit_room').notNull().unique(),
});

export const roomMembers = pgTable('room_members', {
  roomId: uuid('room_id').notNull().references(() => rooms.id, { onDelete: 'cascade' }),
  userId: text('user_id').notNull().references(() => users.id),
  role: memberRole('role').notNull(),
  grantedBy: text('granted_by').references(() => users.id),
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow(),
}, (t) => ({ uniqMember: unique().on(t.roomId, t.userId) }));

export const roomBans = pgTable('room_bans', {
  roomId: uuid('room_id').notNull().references(() => rooms.id, { onDelete: 'cascade' }),
  userId: text('user_id').notNull().references(() => users.id),
  bannedBy: text('banned_by').references(() => users.id),
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow(),
}, (t) => ({ uniqBan: unique().on(t.roomId, t.userId) }));
```

```ts
'use client';
import { MEWE_MSG, type HostDisplay } from './messages';

/** Exact-match origin comparison. Never use startsWith or includes here. */
export function isTrustedMessage(e: MessageEvent, expectedOrigin: string): boolean {
  return e.origin === expectedOrigin;
}

export function handshake(expectedOrigin: string, timeoutMs = 10_000) {
  return new Promise<{ loginRequestToken: string; meweHost: string }>((resolve, reject) => {
    const timer = setTimeout(() => {
      window.removeEventListener('message', onMessage);
      reject(new Error('handshake-timeout'));
    }, timeoutMs);

    function onMessage(e: MessageEvent) {
      if (!isTrustedMessage(e, expectedOrigin)) return;          // ignore silently
      if (e.data?.type !== MEWE_MSG.HOST_HANDSHAKE_RESPONSE) return;
      clearTimeout(timer);
      window.removeEventListener('message', onMessage);
      resolve({ loginRequestToken: e.data.loginRequestToken, meweHost: e.data.meweHost });
    }

    window.addEventListener('message', onMessage);
    window.parent.postMessage({ type: MEWE_MSG.CLIENT_HANDSHAKE_REQUEST }, expectedOrigin);
  });
}

export function onLifecycle(
  expectedOrigin: string,
  handlers: {
    onDisplay?: (d: HostDisplay) => void;
    onMinimized?: () => void; onMaximized?: () => void;
    onPaused?: () => void;   onResumed?: () => void;
    onClosed?: () => void;
  },
) {
  function onMessage(e: MessageEvent) {
    if (!isTrustedMessage(e, expectedOrigin)) return;
    switch (e.data?.type) {
      case MEWE_MSG.HOST_DISPLAY_RESPONSE: handlers.onDisplay?.(e.data); break;
      case MEWE_MSG.HOST_APP_MINIMIZED:    handlers.onMinimized?.(); break;
      case MEWE_MSG.HOST_APP_MAXIMIZED:    handlers.onMaximized?.(); break;
      case MEWE_MSG.HOST_APP_PAUSED:       handlers.onPaused?.(); break;
      case MEWE_MSG.HOST_APP_RESUMED:      handlers.onResumed?.(); break;
      case MEWE_MSG.HOST_APP_CLOSED:       handlers.onClosed?.(); break;
    }
  }
  window.addEventListener('message', onMessage);
  window.parent.postMessage({ type: MEWE_MSG.CLIENT_DISPLAY_REQUEST }, expectedOrigin);
  return () => window.removeEventListener('message', onMessage);
}
```

```ts
import { AccessToken } from 'livekit-server-sdk';
import { canPublish, type Role } from '@/lib/auth/roles';

export function grantsFor(role: Role) {
  return {
    roomJoin: true,
    canSubscribe: true,
    canPublish: canPublish(role),   // the single source of truth
    canPublishData: true,           // chat + reactions for everyone
  };
}

export async function mintToken(opts: {
  identity: string; name: string; room: string; role: Role;
}) {
  const at = new AccessToken(process.env.LIVEKIT_API_KEY!, process.env.LIVEKIT_API_SECRET!, {
    identity: opts.identity,   // MeWe user id — a second tab displaces the first
    name: opts.name,
    ttl: '4h',                 // deliberately independent of the MeWe token lifetime
  });
  at.addGrant({ room: opts.room, ...grantsFor(opts.role) });
  return at.toJwt();
}
```

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getSession } from '@/lib/session';
import { getRoom, getRoleInRoom, countByRole } from '@/lib/rooms/queries';
import { evaluate } from '@/lib/auth/guard';
import { SPEAKER_CAP } from '@/lib/auth/roles';
import { setCanPublish } from '@/lib/livekit/admin';
import { db } from '@/lib/db';
import { roomMembers } from '@/lib/db/schema';

const Body = z.object({ userId: z.string().min(1) });

export async function POST(req: Request, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const session = await getSession();
  if (!session.userId) return NextResponse.json({ error: 'no-session' }, { status: 401 });

  const parsed = Body.safeParse(await req.json());
  if (!parsed.success) return NextResponse.json({ error: 'bad-request' }, { status: 400 });

  const room = await getRoom(id);
  if (!room) return NextResponse.json({ error: 'not-found' }, { status: 404 });

  const actor = await getRoleInRoom(id, session.userId);
  const target = await getRoleInRoom(id, parsed.data.userId);
  const g = evaluate(actor, target, 'promote');
  if (!g.ok) return NextResponse.json({ error: g.error }, { status: g.status });

  if (await countByRole(id, 'speaker') >= SPEAKER_CAP) {
    return NextResponse.json({ error: 'speaker-cap-reached' }, { status: 409 });
  }

  // Database FIRST. A crash after this leaves a speaker who reconnects correctly —
  // the recoverable failure. The reverse order strands a speaker no record knows about.
  await db.insert(roomMembers)
    .values({ roomId: id, userId: parsed.data.userId, role: 'speaker', grantedBy: session.userId })
    .onConflictDoUpdate({
      target: [roomMembers.roomId, roomMembers.userId],
      set: { role: 'speaker', grantedBy: session.userId },
    });

  await setCanPublish(room.livekitRoom, parsed.data.userId, true);
  return NextResponse.json({ ok: true });
}
```

```ts
import { NextResponse } from 'next/server';
import { WebhookReceiver } from 'livekit-server-sdk';
import { db } from '@/lib/db';
import { rooms } from '@/lib/db/schema';
import { eq, sql } from 'drizzle-orm';
import { scheduleHostGrace } from '@/lib/rooms/host-grace';

const receiver = new WebhookReceiver(process.env.LIVEKIT_API_KEY!, process.env.LIVEKIT_API_SECRET!);

export async function POST(req: Request) {
  const body = await req.text();
  const auth = req.headers.get('Authorization');
  if (!auth) return NextResponse.json({ error: 'unsigned' }, { status: 401 });

  let event;
  try {
    event = await receiver.receive(body, auth);   // throws on bad signature
  } catch {
    return NextResponse.json({ error: 'bad-signature' }, { status: 401 });
  }

  const lkRoom = event.room?.name;
  if (!lkRoom) return NextResponse.json({ ok: true });

  if (event.event === 'participant_joined' || event.event === 'participant_left') {
    const count = event.room?.numParticipants ?? 0;
    await db.update(rooms)
      .set({ peakListeners: sql`GREATEST(${rooms.peakListeners}, ${count})` })
      .where(eq(rooms.livekitRoom, lkRoom));
  }

  if (event.event === 'participant_left' && event.participant?.identity) {
    await scheduleHostGrace(lkRoom, event.participant.identity);
  }

  return NextResponse.json({ ok: true });
}
```

```tsx
'use client';
import { useEffect } from 'react';

export function useLocalCaptions(enabled: boolean, publish: (text: string, final: boolean) => void) {
  useEffect(() => {
    if (!enabled) return;
    const SR = (window as any).SpeechRecognition ?? (window as any).webkitSpeechRecognition;
    if (!SR) return;                       // unsupported browser: silently no captions

    const rec = new SR();
    rec.continuous = true;
    rec.interimResults = true;
    rec.onresult = (e: any) => {
      const r = e.results[e.results.length - 1];
      publish(r[0].transcript, r.isFinal);
    };
    // The API stops on silence; restart so captions survive a pause.
    rec.onend = () => { try { rec.start(); } catch {} };
    rec.start();
    return () => { rec.onend = null; rec.stop(); };
  }, [enabled, publish]);
}
```
